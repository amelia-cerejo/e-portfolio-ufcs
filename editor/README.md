# Aplicação de E-Portefólio

Editor local do e-portefólio. `npm ci` instala as dependências; `npm run dev` inicia o servidor local. `npm run build` gera a aplicação estática em `../site/app/` para publicação no site principal.

Os projetos são guardados no navegador e podem ser descarregados como ficheiros `.eportfolio`. Não existe publicação automática nem conta de formando no servidor.
